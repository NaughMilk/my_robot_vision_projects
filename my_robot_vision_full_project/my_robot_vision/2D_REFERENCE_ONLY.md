# 2D Reference Only

## Scope

Phan 2D trong repository nay chi dung de tham khao.

Huong phat trien dang lam la mo phong 3D bang Gazebo.

## Working Rule

- Khong sua code 2D neu khong co yeu cau ro rang tu nguoi dung.
- Khong dung phan 2D lam muc tieu chinh cho cac thay doi moi.
- Khi can tham khao logic cu tu 2D, chi doc de doi chieu voi huong trien khai 3D Gazebo.
- Uu tien cac file va luong chay lien quan den Gazebo 3D khi phat trien tiep.

## 3D Gazebo Focus

Nhung thay doi moi nen huong vao cac thanh phan 3D Gazebo nhu:

- Gazebo world va model 3D.
- Launch file cho mo phong Gazebo.
- Node dieu khien va quan sat robot trong Gazebo.
- Tai nguyen sinh ra cho map va mesh 3D.

## Note

Neu mot thay doi co nguy co cham vao code 2D, dung lai va xac nhan lai pham vi truoc khi sua.
